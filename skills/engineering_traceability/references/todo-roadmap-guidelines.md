# TODO / Roadmap Guidelines

## Classification
- Discussion: exploratory, uncertain, not implementation-ready.
- Issue: actionable engineering task.
- Milestone: grouped delivery window.

## Logging rules
- Any TODO in chat/docs must become Discussion or Issue.
- Use Issues for work that can start now.
- Use Discussions for ideation; promote to Issues when actionable.

## Scoping rules
Each Issue must define:
- in-scope
- out-of-scope
- acceptance criteria
- test evidence expected

## Roadmap decomposition
- Epics should be milestone-backed.
- Break epics into PR-sized Issues.
- Track blockers via linked Issues, not comments-only.

## Status hygiene
Use labels consistently:
- type: bug|feature|refactor|ops
- priority: P0|P1|P2
- state: todo|in-progress|blocked|review|done
- area: <module/team>
