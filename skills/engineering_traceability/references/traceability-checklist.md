# Traceability Checklist

For each delivered change, verify:

- [ ] Discussion exists for idea-stage work (if applicable)
- [ ] Actionable work tracked in Issue(s)
- [ ] Branch references issue id
- [ ] Commit messages reference issue id
- [ ] PR links/closes issue
- [ ] PR contains test evidence
- [ ] Review comments resolved with commit context
- [ ] Merge SHA recorded in PR timeline
- [ ] Follow-up tasks logged as Issues
- [ ] No orphan TODOs in chat/docs without GitHub artifact
